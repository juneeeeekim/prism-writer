    - `Target`: `MarkdownEditor.tsx` > 새 `useEffect` 훅 (Line 48 근처)
    - `Logic (Pseudo)`:
      ```typescript
      useEffect(() => {
        // 1. SSR 환경 체크
        if (typeof window === 'undefined') return

        // 2. MediaQueryList 생성
        const mediaQuery = window.matchMedia('(prefers-color-scheme: dark)')

        // 3. 초기값 설정
        setIsDarkMode(mediaQuery.matches)

        // 4. 변경 리스너 등록
        const handleChange = (e: MediaQueryListEvent) => {
          setIsDarkMode(e.matches)
        }
        mediaQuery.addEventListener('change', handleChange)

        // 5. Cleanup
        return () => mediaQuery.removeEventListener('change', handleChange)
      }, [])
      ```
    - `Key Variables`:
      - `mediaQuery: MediaQueryList` - 시스템 테마 감지 객체
      - `handleChange: (e: MediaQueryListEvent) => void` - 테마 변경 핸들러
    - `Safety`:
      - ✅ `typeof window === 'undefined'` 체크 필수 (SSR 대응)
      - ✅ cleanup 함수에서 `removeEventListener` 필수 (메모리 누수 방지)
