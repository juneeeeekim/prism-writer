## 1. 문제 현상

macOS에서 시스템 다크 모드를 사용할 때, 마크다운 에디터의 글씨가 보이지 않는 현상이 발생합니다.

### 재현 조건
- **OS**: macOS (Ventura, Sonoma 등)
- **시스템 설정**: 시스템 환경설정 > 일반 > 다크 모드 활성화
- **브라우저**: Safari, Chrome, Firefox 모두 동일

### 증상
| 환경 | 배경색 | 글자색 | 결과 |
|------|--------|--------|------|
| Windows / macOS 라이트 모드 | 흰색 (#ffffff) | 검정 (#24292f) | ✅ 정상 |
| macOS 다크 모드 | 어두운 회색 | 검정 (#24292f) | ❌ 글씨 안 보임 |

## 2. 원인 분석

### 2.1 핵심 원인: `data-color-mode` 하드코딩

**파일**: `frontend/src/components/Editor/MarkdownEditor.tsx`
**위치**: 134번 줄

```tsx
<div
  id="markdown-editor-container"
  className="flex-1 overflow-hidden"
  data-color-mode="light"  // ⚠️ 항상 "light"로 고정!
>
```

#### 왜 문제인가?

`@uiw/react-md-editor` 라이브러리는 `data-color-mode` 속성을 기준으로 테마를 결정합니다:

```css
/* 라이브러리 내부 CSS (node_modules/@uiw/react-md-editor/dist/mdeditor.css) */

/* Light Mode - data-color-mode="light"일 때 적용 */
[data-color-mode*='light'] .wmde-markdown {
  --color-fg-default: #24292f;       /* 어두운 텍스트 */
  --color-canvas-default: #f6f8fa;   /* 밝은 배경 */
}

/* Dark Mode - data-color-mode="dark"일 때 적용 */
[data-color-mode*='dark'] .wmde-markdown {
  --color-fg-default: #c9d1d9;       /* 밝은 텍스트 */
  --color-canvas-default: #0d1117;   /* 어두운 배경 */
}
```

현재 `data-color-mode="light"`로 고정되어 있으므로, 시스템이 다크 모드여도 라이브러리는 항상 라이트 모드 스타일(검정 글씨)을 적용합니다.

### 2.2 부가 원인: CSS 오버라이드 선택자 우선순위 문제

**파일**: `frontend/src/app/globals.css`
**위치**: 103-107번 줄

```css
/* Markdown editor dark mode override */
.dark .w-md-editor {
  --color-canvas-default: #1f2937;
  --color-fg-default: #f9fafb;
}
```

#### 왜 작동하지 않는가?

1. **선택자 명시도 문제**: 라이브러리의 `[data-color-mode*='light']` 선택자가 `.dark .w-md-editor`보다 더 구체적
2. **속성 선택자 우선**: `data-color-mode="light"`가 명시되어 있으면 라이브러리 CSS가 우선 적용
3. **CSS 변수 범위**: 라이브러리 내부에서 재정의되어 외부 오버라이드가 무시됨

## 4. 해결 방법

### 4.1 방법 1: 동적 `data-color-mode` 적용 (권장)

시스템 테마에 따라 `data-color-mode`를 동적으로 변경합니다.

```tsx
// MarkdownEditor.tsx 수정

import { useEffect, useState } from 'react'

export default function MarkdownEditor() {
  // 시스템 다크 모드 감지
  const [isDarkMode, setIsDarkMode] = useState(false)

  useEffect(() => {
    // 초기값 설정
    const darkModeMediaQuery = window.matchMedia('(prefers-color-scheme: dark)')
    setIsDarkMode(darkModeMediaQuery.matches)

    // 변경 감지 리스너
    const handler = (e: MediaQueryListEvent) => setIsDarkMode(e.matches)
    darkModeMediaQuery.addEventListener('change', handler)

    return () => darkModeMediaQuery.removeEventListener('change', handler)
  }, [])

  return (
    <div className="flex flex-col h-full">
      {/* ... 기존 코드 ... */}

      <div
        id="markdown-editor-container"
        className="flex-1 overflow-hidden"
        data-color-mode={isDarkMode ? 'dark' : 'light'}  // ✅ 동적 적용
      >
        <MDEditor
          value={content}
          onChange={(value) => setContent(value || '')}
          height="100%"
          preview="edit"
        />
      </div>
    </div>
  )
}
```

### 4.2 방법 2: Tailwind 클래스 기반 감지 (대안)

프로젝트가 Tailwind의 `darkMode: 'class'`를 사용하므로, `<html class="dark">`를 감지할 수도 있습니다.

```tsx
// HTML element의 dark 클래스 감지
const [isDarkMode, setIsDarkMode] = useState(false)

useEffect(() => {
  const checkDarkMode = () => {
    setIsDarkMode(document.documentElement.classList.contains('dark'))
  }

  checkDarkMode()

  // MutationObserver로 클래스 변경 감지
  const observer = new MutationObserver(checkDarkMode)
  observer.observe(document.documentElement, {
    attributes: true,
    attributeFilter: ['class']
  })

  return () => observer.disconnect()
}, [])
```

### 4.3 방법 3: CSS 강제 오버라이드 (임시 해결)

CSS 선택자 명시도를 높여 강제 오버라이드합니다.

```css
/* globals.css에 추가 */

/* 강제 다크 모드 오버라이드 (높은 명시도) */
html.dark #markdown-editor-container[data-color-mode] .w-md-editor,
html.dark #markdown-editor-container[data-color-mode] .w-md-editor-text,
html.dark #markdown-editor-container[data-color-mode] .w-md-editor-text-pre,
html.dark #markdown-editor-container[data-color-mode] .w-md-editor-text-input,
html.dark #markdown-editor-container[data-color-mode] .wmde-markdown {
  --color-canvas-default: #1f2937 !important;
  --color-fg-default: #f9fafb !important;
  background-color: #1f2937 !important;
  color: #f9fafb !important;
}

/* 에디터 textarea 직접 스타일링 */
html.dark #markdown-editor-container .w-md-editor-text-input {
  color: #f9fafb !important;
  caret-color: #f9fafb !important;
}
```
