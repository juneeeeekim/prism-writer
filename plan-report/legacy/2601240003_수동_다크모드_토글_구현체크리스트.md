## [Phase 1: 전역 테마 상태 관리 (Context API)]

**Before Start:**

- ⚠️ **Hydration Mismatch**: 서버(SSR)와 클라이언트(CSR)의 테마 불일치로 인한 화면 깜빡임 방지 필수. `useState<Theme | null>(null)`로 초기화하여 클라이언트 마운트 전에는 렌더링을 지연하거나 스켈레톤 처리 고려.
- ⚠️ **Persistence**: `localStorage` 접근 시 항상 `typeof window !== 'undefined'` 체크.

**Implementation Items:**

- [x] **ID(P1-01)**: `ThemeContext` 및 `ThemeProvider` 구현 ✅ (2026-01-24 완료)
  - `Target`: `frontend/src/contexts/ThemeContext.tsx`
  - `Logic (Pseudo)`:

    ```typescript
    type Theme = 'light' | 'dark';

    // Context 생성
    const ThemeContext = createContext<{ theme: Theme | null; toggleTheme: () => void } | undefined>(undefined);

    export function ThemeProvider({ children }) {
      const [theme, setTheme] = useState<Theme | null>(null);

      useEffect(() => {
        // 1. LocalStorage 우선 확인
        const stored = localStorage.getItem('theme') as Theme;
        // 2. System Preference 확인
        const system = window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';

        const finalTheme = stored || system;
        setTheme(finalTheme);

        // CSS Class 적용
        document.documentElement.classList.toggle('dark', finalTheme === 'dark');
      }, []);

      const toggleTheme = () => {
        if (!theme) return;
        const newTheme = theme === 'dark' ? 'light' : 'dark';
        setTheme(newTheme);
        localStorage.setItem('theme', newTheme);
        document.documentElement.classList.toggle('dark', newTheme === 'dark');
      };

      return <ThemeContext.Provider value={{ theme, toggleTheme }}>{children}</ThemeContext.Provider>;
    }
    ```

  - `Key Variables`: `theme` (null check 필수), `toggleTheme`
  - `Safety`: `useEffect` 내부에서만 `window` 및 `localStorage` 접근

- [x] **ID(P1-02)**: Root Layout에 Provider 적용 ✅ (2026-01-24 완료)

**Implementation Items:**

- [x] **ID(P2-01)**: `ThemeToggle` 버튼 컴포넌트 구현 ✅ (2026-01-24 완료)
  - `Target`: `frontend/src/components/layout/ThemeToggle.tsx`
  - `Logic (Pseudo)`:

    ```typescript
    import { SunIcon, MoonIcon } from '@heroicons/react/24/outline'; // or solid

    export default function ThemeToggle() {
      const { theme, toggleTheme } = useTheme();

      // Hydration Mismatch 방지: theme이 null이면 렌더링 안 함 (또는 스켈레톤)
      if (!theme) return null;

      return (
        <button onClick={toggleTheme} className="p-2 rounded-lg hover:bg-gray-100 dark:hover:bg-gray-800 transition-colors">
          {theme === 'dark' ? <SunIcon className="w-5 h-5 text-yellow-500" /> : <MoonIcon className="w-5 h-5 text-gray-500" />}
        </button>
      );
    }
    ```

  - `Key Variables`: `theme` (null check)
  - `Safety`: 버튼 클릭 시 `toggleTheme`이 `undefined`일 경우 예외 처리 (Context Hook에서 처리됨)
